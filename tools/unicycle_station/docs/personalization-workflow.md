# Run 会话与个性化显示 · 0.4

2026-09-07。Windows 程序位于 `tools/unicycle_station/dist/personalization-workflow/EmbeddedStation/EmbeddedStation.exe`，迁移时复制整个 `EmbeddedStation` 文件夹。0.2、0.3 安装包保留。

本版只修改上位机，继续使用现有协议，无需为本次更新重新烧录车端。本轮没有 ADS 构建、烧录和实车串口操作。界面缩放、撤销、折叠和拖动功能继续可用，见 [0.3 操作说明](interaction-workflow.md)。

## 任务与轨迹按 Run 记录

- 未进入 Run：页面显示“等待 Run 开始”，不积累道路事件和轨迹。
- Run 开始：自动清空上一次道路事件、轨迹和累计路程，从原点重新估算，并显示本次 Run 编号。
- Run 结束：停止更新，保留本次结果供查看与导出，下一次 Run 自动清空。
- 使用车端明确的 Run 标志，不把 Balance、Test、Jog 当作 Run；结束 Run 后仍保持平衡，也会停止本页记录。
- 串口连接中途遇到正在运行的 Run，从首次观测到 Run 时开始本次记录。回放同样按收到的 Run 标志处理，跳转回放后从新位置重新建立记录。

这里清空的是任务页的当前结果；原始会话日志、试验归档和其他波形数据不会被删除。轨迹仍是轮速与航向积分的相对估算，缺口分段、存在打滑与航向漂移，不是绝对定位。

## 自定义参数和组的显示名称

选中参数行或组标题，点击工具栏“显示名称”、按 **F2**，或者右键选择“自定义显示名称”。输入新名称并确定，留空或右键“恢复默认名称”可恢复原名。

别名只改变上位机显示。参数名称下方仍保留固定的程序名，例如 `r_rate_kp`；参数对象、串口命令、组归属、预设中的键名、RAM 写入和 Flash 保存标识保持不变。搜索支持别名、原中文名和程序名。参数页和工作台共享别名，总览的参数读回卡也显示相同别名。可以用 Ctrl+Z 撤销改名。

## 总览显示项目

点击右上角 **“显示项目”**，搜索并勾选需要的内容，然后确定。可以选择运行遥测、派生状态以及参数的 MCU 读回值；支持全选/取消当前搜索结果和恢复默认项目。

右键卡片可直接隐藏，拖动卡片调整顺序。隐藏全部项目后仍保留添加入口。显示项目、顺序、别名随工作区保存，显隐也可以撤销。参数卡显示已读回的 MCU 值，不会把本地待应用值当成车端当前值；尚未读取的参数明确显示“待读取”。

## 没有波形时怎么操作

1. 连接成功后，在“实时波形”点击 **“显示姿态”**，快速显示 `att_roll`、`pitch`、`yaw`。
2. 左侧通道会标注“接收中 / 已过期 / 未收到”。选择目标图表后，勾选通道立即绘制，无需再点应用。切换目标图表时，勾选状态同步为该图实际选择的通道。
3. 点 **“恢复实时显示”**，重新显示隐藏图表、取消暂停、跟随最新数据并恢复纵轴自动缩放。每张图也提供“恢复实时”按钮。
4. 看图上方的说明，区分未选择通道、该通道尚未收到数据、数据过期、暂停和未跟随。

当前车端 `att` 的横滚通道名是 **`att_roll`**，完整 `run` 帧里的横滚通道名是 **`roll`**。二者来源不同；只收到姿态帧时，选择 `roll` 不会产生曲线。源码中 Run 全量诊断在进入 Run 时启用，姿态辅助数据则在握手后发送；串口连接成功并不代表所有 Run 通道都已上报。先用“显示姿态”检查，无需为了让图表出现曲线而发车。

本版另外修复了两个绘图问题：旧工作区恢复坐标范围时意外关闭纵轴自动缩放，以及串口数据集中到达时自动降采样可能把整批曲线变成空数据。新工作区会明确保存纵轴自动/手动状态，旧工作区默认恢复自动纵轴；手动范围仍可在“范围”中设置。
