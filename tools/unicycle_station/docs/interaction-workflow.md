# 交互优化版 0.3

程序入口：`tools/unicycle_station/dist/EmbeddedStation/EmbeddedStation.exe`。复制到其他电脑时，请复制整个 `EmbeddedStation` 文件夹。

本版只更新上位机，不改变通信协议和车端控制逻辑；已能正常连接的车端无需重新烧录。本轮没有进行 ADS 构建、烧录或实车串口操作。

## 缩放界面

- 按住 **Ctrl + 滚轮**，调整界面到 70%～160%，每格变化 10%。字体、间距、表格行高及总览排列一起调整。
- **Ctrl + 0** 恢复 100%；也可以使用“视图”菜单。当前比例显示在底部。
- 普通滚轮继续用于滚动表格或操作图表、3D 视图。按住 Ctrl 时优先缩放界面，不修改鼠标下面的参数值。
- 大比例下，超出的内容通过滚动查看；缩小适合同时观察更多参数。

## 撤销与重做

**Ctrl + Z** 撤销，**Ctrl + Shift + Z / Ctrl + Y** 重做；“编辑”菜单和参数工具栏也提供入口。最多保留本次工作区的 100 步历史。

可撤销参数编辑、步长/百分比微调、预设批量导入、清除待修改、回退上次值、收藏、显示排序、图表通道选择和 3D 显示方向修改。输入框中尚未提交的文字优先使用文字撤销。

**参数撤销只修改本地“待应用值”。** 如果新值已写入车端，撤销会把旧值放回待应用栏，需要再次点击“应用”并核对差异才会写入车端。收到车端应答时，也会保留应答等待期间新做的撤销操作。撤销不会自动发送停车、参数写入或 Flash 保存命令。

历史不跨越工作区载入、设备 Profile 切换或程序重启；这些操作会清空历史。串口连接、记录文件、车端运行状态及 Flash 操作不属于撤销范围。

## 参数分组与折叠

参数按功能分组，Roll/Pitch/Yaw 进一步按角速度环、角度环、速度环或飞轮回收环显示。点击组标题即可展开、收起；工具栏提供“全部展开 / 全部收起”。标题显示当前匹配项数和待应用修改数。

搜索会临时展开匹配项，清空搜索后恢复原来的折叠状态。参数页与调参工作台共享组内顺序、收藏及折叠设置。分组只改变显示方式，车端的参数归属、写入权限和 Flash 保存分组保持原有规则。

## 拖动排序

| 内容 | 操作 |
| --- | --- |
| 参数分组 | 拖动组标题，调整整个分组的位置 |
| 组内参数 | 拖动参数名称前的点阵或名称，放到同组目标项的上方或下方 |
| 参数表格列 | 拖动列标题，例如把“待应用值”移到更靠前的位置 |
| 总览数值卡片 | 按住卡片拖到其他卡片的位置 |
| 实时波形通道 | 拖动左侧通道列表中的条目 |

参数拖动时有插入位置提示，接近表格上下边缘时自动滚动。参数不能通过拖动改到另一个功能组；要移动整组，请拖动组标题。上述排序都可以撤销。

缩放比例、分组顺序、组内排序、折叠状态、表格列布局、总览卡片和通道顺序随工作区保存，正常退出后的自动恢复也会保留这些设置。旧版工作区没有这些字段时使用默认布局。

原有任务状态、轨迹、试验对比、故障截取、波形、记录回放、RAM 写入与 Flash 功能继续使用原来的操作方式，见 [调试增强版说明](debug-workflow.md)。
