# 0.5.0 界面体验与遥控

程序固定入口为 `tools/unicycle_station/dist/EmbeddedStation/EmbeddedStation.exe`，也可双击上位机目录的 `start_app.bat`。只保留一个当前安装包。

## 界面改进

- Ctrl+滚轮每格 5%，合并 35 ms 内的滚轮事件；Ctrl+0 恢复 100%。状态栏比例按钮提供常用比例，范围仍为 70%–160%。普通滚轮仍用于页面、图表或 3D 操作。
- 总览样式只在状态变化时更新，隐藏页面暂停刷新，避免缩放后重复设置同样的样式。
- 字号继承统一基准，避免反复缩放及新建控件时重复放大。缩放后保留页面的相对滚动位置。
- 总览卡片根据实际窗口宽度重排，窄窗口可降为单列；长状态文字换行，并提供完整提示。
- 优化深浅色层次、留白、滚动条及按钮状态，去除底部重复链路信息。导航选中标记使用 160 ms 动画；“视图 → 界面动效”可关闭，配置随工作区保存。实时波形和 3D 不叠加淡入效果。

## 遥控使用

1. 更新车端源码并按原流程构建、烧录。新版新增只读 `cfg:remote` 查询；旧固件的监看和调参继续可用，遥控会提示更新。
2. 在车身菜单 Run Test → Remote 确认启动，等待上位机“Remote 已确认”。上位机不远程启动电机。
3. 打开“遥控驾驶”，选择速度和转向幅度，勾选“启用本次遥控”。默认 0.15 m/s、10°，界面限制为 0.05–0.50 m/s、5–30°。
4. 按住 W/S 或上下键前进/后退，A/D 或左右键转向；可同时按住前进和转向。也可使用方向按钮。左右方向遵循车端 steer_dir，首次使用需低速核对车体方向。
5. 松开方向回零并保留平衡；Esc、“释放”、切换页面、窗口失焦解除本次遥控，必须再次启用。Space 或顶部“立即停车”走既有优先停车通道，停止电机。

Mock 演示中的“模拟进入 Remote”只改变本机模拟设备，不发送远程发车命令。实际实车是否运动应依据观察及车端反馈；页面区分操作目标和车端最近命令，不将命令值当作实测速度。

## 通信与保护

运动命令使用已有 `speed:<相对航向角>,<速度×40>`，每秒最多 10 次，采用最新输入覆盖，避免排队重放旧方向。只读状态查询在遥控页约每秒 4 次，复用带序号请求并让配置请求先完成。满负荷下新增下行约 350 B/s、上行约 300 B/s，实际以通信诊断计数为准。

只有配置握手成功、Remote 应答新鲜、车端模式为 Balance 且未处于 Run/Test/Jog 时才能启用。界面输入心跳中断超过 300 ms 时，通信线程自行回零并解除遥控；状态过期同样释放。释放时重复发送三次零指令，关闭连接前尽力发送一次。停止优先级高于遥控，重连和回放不恢复遥控授权。

车端仍保留 1000 ms 命令超时门槛；本版补充超时时清除旧转向意图并捕获当前航向，同时沿用原有速度归零和平衡逻辑。串口完全断开时无法保证零指令到达，车端超时保护负责兜底。此时间是软件门槛，不是机械停车距离或停车耗时。

本轮不执行 ADS 构建、烧录或实车运动；PC/Mock 与主机协议契约检查不替代台架验证。
